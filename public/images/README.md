# Imagens

Todas as imagens foram desenhadas por mim em SVG (sem usar arte oficial dos jogos).

| Arquivo | Uso |
|---------|-----|
| `favicon.svg` | Ícone da aba do navegador |
| `avatar-*.svg` | Foto de perfil de cada personagem |
| `post-*.svg` | Foto de cada publicação |

Para trocar, coloque a imagem nesta pasta e mude o caminho em `src/data/posts.json`.
